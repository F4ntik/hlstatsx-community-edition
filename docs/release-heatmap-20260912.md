# Кандидат выпуска: отображение тепловой карты

12 сентября 2026. На принятую основу Python+i18n добавлены подготовленные поверхности
BSP всех 25 стандартных карт и обновлённое отображение. Повторный приём и разбор
журналов не выполнялся: каталоги движка, прокси, `hlx_core`, SQL, amxmodx и sourcemod
совпадают с ранее принятым `d80d6d5`.

## Изменения для пользователя

- Более компактные и заметные отдельные события; переключатель «Чётко / Мягко».
- В «Оба» убийства остаются тёплыми, смерти голубыми. Сглаживание раздельное,
  числовой масштаб общий; пересечение светлее. Точки и ячейки тоже сохраняют оба канала.
- Инвертированный вариант цветной подложки; для сравнения каналов удобен Ч/Б.
- Название в русском интерфейсе — «тепловая карта».
- При подготовке BSP вместе с JPEG/координатами автоматически рассчитываются поверхности.
  При просмотре загружается готовый файл, без повторной обработки BSP.

Построение границ и значения параметров: [отображение](heatmap-display.md).
Подготовка карт и явная установка файлов: [импорт BSP](heatmap-bsp-registration.md).

## Проверка изменения

Пройдены направленные JavaScript-проверки отображения и контрактов, включая оба канала
в точках, общую шкалу, неизменность Difference и отсутствие чередования яркости в одиночном
пятне. Проверены PHP-разметка и загрузка новых переводов. Два коротких теста импортера
проверяют вызов расчёта после окончательного JPEG и сохранение других карт при публикации.
Реальный импорт dust2 занял 12,265 с и получил прежний SHA-256 графа без расхождений.
Независимый обзор завершён; исправлена доступность публикуемых JSON веб-серверу на Linux.

В браузере проверены оба цвета в плавном режиме, ячейках и точках; переключение чёткости,
инверсия и Ч/Б; корректная легенда и числовая шкала. Снимки сохранены в локальном HTML-отчёте.

[Свежие измерения](audits/bsp-visual-performance-20260912.json) выполнены в Node по весам
до миллиона событий, не по миллиону строк базы и не по FPS. Чёткий режим «Оба»: dust2
11,1–25,5 мс, as_oilrig 26,5–34,9 мс. Мягкий «Оба» на as_oilrig: 78,7–133,5 мс.
Перемещение карты использует кэш. Предел выборки 250 000 исходных строк сохранён.

## Состав выпуска

Install содержит все 25 карт. Upgrade обновляет только JSON поверхностей и их настройку
сжатия; изображения карт, их привязка, SQL установки и живые настройки исключены.
Инструменты подготовки поставляются полным комплектом; дополнительные зависимости
NumPy/Pillow нужны только оператору импорта. Файлы игры и лабораторные отчёты в архивы
не входят. См. [установку и обновление](release-install-upgrade.md).

Архивы строятся из окончательного коммита. Внешний manifest содержит точный commit и
SHA-256 архивов/файлов; приёмка упаковки проверяет этот состав и сохранность пользовательских
изображений и конфигурации при пробном наложении. Публикация релиза и обновление работающего
общедоступного сайта не выполняются автоматически.
