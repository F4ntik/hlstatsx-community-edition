# Улучшения теплокарты — 8 сентября 2026

Работа продолжена поверх локальных изменений 7 сентября в
`feature/modern-heatmap-explorer`. Пункт 2 из обсуждения (хранение и проверка
версии BSP) исключён по указанию владельца. После уточнения владельца все
изменения и проверки выполнял основной агент; независимое ревью этого этапа
не заявляется. Исходный стенд на 8281 не изменялся, изменения не публиковались.

## Результат

- Обычные даты UTC вместо редактирования секунд; точность до секунды и прежние URL.
- Одна строка состояния, сведения о данных раскрываются отдельно. Заголовок
  общей статистики больше не выдаёт все сохранённые записи за жёсткий период.
- Числовая шкала и закрепление её максимума между совместимыми периодами.
- Необязательные области этажей, согласованный отбор карты/точек/списков событий,
  отдельные JPEG этажей с тем же размером и полем изображения.
- Обрезка отрисовки по контурам и ограничение сглаживания маской сетки.
- Импорт JSON-кандидата, безопасное наложение числовых SVG-контуров, выбор
  пиксельных координат ориентиров мышью и рисование областей этажа.

## Ограничения

Контуры нужно задать для конкретного этажа. Это не автоматическое восстановление
проходимости BSP и не учёт каждой стены; сглаживание ограничено разрешением
сетки, а пиксели обрезаются по полигону. Все этажи вместе показываются без маски.
Отдельные картинки должны совпадать по положению, не только по размеру.
Закрепление шкалы действует до перезагрузки страницы и не переносится ссылкой.
Регистрация версии BSP и новые подтверждения исторических событий не добавлялись.

## Продолжение: редактор этажей и стен через настройки

По следующему запросу пользователя ручные действия перенесены в веб-форму.
Корневой агент выполнил работу самостоятельно. Это продолжение меняет прежнее
условие сохранения: неизменная привязка позволяет сохранять этажи без повторного
ввода ориентиров, но с одноразовым подтверждением предпросмотра. Изменения
привязки сохраняются только после прежней проверки ориентиров.

- В браузере добавлен этаж, нарисована стена из четырёх точек, настройки
  сохранены и прочитаны обратно. Отмена последней точки дала 1 вместо 2;
