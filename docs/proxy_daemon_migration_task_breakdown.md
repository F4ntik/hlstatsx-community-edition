# План задач для переписывания proxy-daemon.pl на Python

Документ описывает разбивку на задачи для команды разработки в продолжение
архитектурного плана из `proxy_daemon_python_migration.md`. Каждый эпик можно
реализовывать параллельно с учётом зависимостей, указанных в пункте
"Подготовка".

## Как пользоваться документом

Отмечайте чекбокс задачи по мере выполнения и оставляйте краткий комментарий
о проделанной работе в строке `Комментарий`. Комментарий может содержать ссылки
на пул-реквесты, коммиты или основные итоги.
