# Интерактивные графики: первая версия

Первый участок перехода — динамика игрока. Остальные графики сайта пока сохраняют
свой существующий способ отображения.

## Разделение данных и отображения

Сервер получает последние 30 доступных записей истории игрока. Подготовка данных
отделена от представления: графику передаются время, рейтинг и изменение рейтинга.
Браузер строит SVG по этим значениям. Для просмотра больше не требуется сохранять
картинку в `hlstatsimg/progress` или запускать старую графическую библиотеку.

В первой версии данные приходят вместе с карточкой игрока: отдельного сетевого
запроса и новой таблицы в базе нет. Объём ограничен 30 записями. Такой контракт
позволяет позже получать те же данные отдельно, если появится выбор большого периода.

## Отображение

- Сохранён компактный вид старого графика: серый фон, жёлтый рейтинг и красное
  изменение за день. Цветные подписи обозначают шкалы: изменение слева, рейтинг справа.
  Пересечение линий не означает равенства показателей: у них разные шкалы.
- Наведение на поле подсвечивает ближайшую запись сразу на обеих линиях.
- Подсказка содержит точную дату с годом и значения записи. Точки доступны с клавиатуры.
- Расстояние по времени отражает даты записей. Пропуски не означают нулевые значения.
- Между точками нет сглаживающей кривой, создающей несуществующие максимумы и минимумы.
- Таблица исходных значений позволяет проверить график и получить данные без JavaScript.
- Русские и английские подписи берутся из переводов интерфейса.

Основа — встроенный в браузер [SVG](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/svg),
без внешнего сервиса, CDN и дополнительной библиотеки графиков.

## Граница изменения

История берётся из существующего хранилища. Расчёт игровых событий, запись рейтинга
и структура базы не меняются. Старый `trend_graph.php` остаётся доступен для
существующих ссылок; ему по-прежнему нужен записываемый каталог `hlstatsimg/progress`.

Это основа для постепенной замены остальных графиков. Для следующего графика сначала
нужно определить смысл показателей, единицы, период, обработку отсутствующих записей
и предел выдачи; затем подключить подходящий способ отображения. Само наличие
интерактивного рисунка не заменяет проверку этих правил.
