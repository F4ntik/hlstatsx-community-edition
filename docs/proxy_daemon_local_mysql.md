# Локальный стенд MySQL для Python-демона

Этот документ описывает минимальную конфигурацию MySQL, подходящую для
разработки и тестирования Python-реализации `proxy-daemon`. Стенд разворачивается
при помощи `docker-compose` и автоматически загружает набор тестовых данных.

> ⚠️ Все шаги ниже предполагают запуск на локальной машине разработчика (Linux,
> macOS, Windows + WSL2). На боевых серверах или общем стенде этот docker-
> compose использовать не требуется.

## Предварительные требования

- Docker и docker-compose (v2 или новее);
- свободный TCP-порт `33060` на хостовой машине.

## Быстрый старт

```bash
cd scripts/proxy_daemon_py
docker compose up -d
```

Команда скачает официальный образ MySQL 8.0, создаст базу `hlstatsx_proxy` и
применит SQL-скрипты из каталога `scripts/proxy_daemon_py/sql`. При первом
запуске будут созданы таблицы `hlstats_Options` и `Proxy_Daemons` с
минимальными значениями. Всё окружение изолировано внутри контейнера и никак не
влияет на рабочие сервера:

- `Proxy_Key` со значением `changeme`;
- `Proxy_Daemons` со списком `127.0.0.1:27900,127.0.0.1:27901`.
- две строки в таблице `Proxy_Daemons` со статусом `n/a` и пустыми отметками
  heartbeat для портов `27900` и `27901`.

Их достаточно, чтобы Python-демон прошёл инициализацию и проверку ключа.

## Подключение к базе

Параметры подключения по умолчанию:

| Параметр | Значение |
| --- | --- |
| host | `127.0.0.1` |
| port | `33060` |
| database | `hlstatsx_proxy` |
| user | `hlstats` |
| password | `hlstats` |

Проверить успешность развёртывания можно при помощи клиента `mysql`. Команда
ниже выполняется на той же локальной машине, где поднят контейнер:

```bash
mysql -h127.0.0.1 -P33060 -uhlstats -phlstats hlstatsx_proxy -e "SELECT * FROM hlstats_Options;"
```

## Обновление тестовых данных

SQL-файлы в `scripts/proxy_daemon_py/sql` выполняются в алфавитном порядке при
каждом первом старте контейнера. Для изменения значений отредактируйте
`01_seed_data.sql` и перезапустите стенд с очисткой тома данных:

```bash
docker compose down -v
docker compose up -d
```

## Остановка стенда

Для остановки контейнера выполните:

```bash
docker compose down
```

Команда удалит контейнер, но сохранит том с данными. Чтобы очистить данные,
используйте флаг `-v`, как показано в разделе выше.
